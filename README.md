# safetysignal — website

SafetySignal AI — AI-native pharmacovigilance.

**Current version: v1.0.0**

`index.html` is the deployed site. It is fully self-contained: all CSS, JavaScript and
the Venture Vertex logo are embedded, and the only external dependency is Google Fonts.
Drop it on any web root, or serve it from GitHub Pages.

## Versioning

The versioned file in this repo is the source of truth. Any future change to this site
starts from the latest version here, not from a local copy.

| File | Purpose |
|---|---|
| `index.html` | Deployed site |
| `safetysignal-website-v1.0.0.html` | Versioned snapshot of the same build |

## Deploy

**GitHub Pages** — Settings, then Pages, then Deploy from branch: `main` / root.

**Any host** — upload `index.html` to the web root.
